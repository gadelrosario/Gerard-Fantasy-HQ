# Gerard Fantasy HQ — Version 1.3

Upload every file and folder in this package to the root of:
gadelrosario/gerard-fantasy-hq

## New in 1.3
- Separate launch screen for:
  - Practice Mock Draft
  - Live Draft Day
- Practice mode:
  - AI opponents enabled
  - Auto-pick button visible
  - Simulation stops at your turn
  - Green visual identity
- Live Draft Day mode:
  - AI disabled
  - Auto-pick hidden
  - Every real league selection is entered manually
  - Blue visual identity
- Change Mode button always visible.
- The selected mode is remembered locally.
- Existing snake tracker, rankings, Gerard Mode, roster tracking, evidence cards, and offline support remain.

## GitHub update
1. Extract the ZIP.
2. Upload all extracted files/folders to the repository root.
3. Replace existing files.
4. Commit changes.
5. Wait for GitHub Pages to redeploy.
6. Reopen the app. If the old version is cached, remove the Home Screen app and add it again from Safari.
