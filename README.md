## New in 1.1
- Gerard Mode remains the default.
- Draft-day screen remains intentionally simple.
- Optional Evidence screen/card added.
- Gerard Adjustments: Love / Neutral / Cautious / Avoid.
- Placeholder fields for:
  - College profile
  - Offseason impact
  - Opportunity/snap trend
  - Evidence confidence
- Fantasyland and BDGE remain the current ranking/intel foundation.
- PWA/offline support retained.

## Important honesty note
The new college, offseason, age, trades, draft-capital, and snap-count framework is now represented in the app structure, but the current player database does not yet contain researched values for every player. Those fields display Pending until verified data is added.

## GitHub update
1. Extract this ZIP.
2. In your repository, replace the old files with the files from this package.
3. Commit the changes.
4. GitHub Pages should update automatically.
5. On iPhone, fully close and reopen the app. If the old version remains cached, remove it from the Home Screen, revisit the website in Safari, and add it again.
